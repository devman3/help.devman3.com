Generate SARS IT3(d) file

Generate your export file by following these easy steps.

You will be able to upload the file directly to SARS.

Go to Finance > SARS IT3 > Exports > Transactions due.

Select the SARS IT3 tax period you wish to export from the drop-down list. 

Entity - select the entity you are exporting the data for.

NOTE: If you have more than one entity, you can:

  • search per entity, then generate separate files.
  • select All entities, and separate files will be automatically generated for each entity.

If you do not have multiple entities registered, this field will not show.

Select the criteria that suit your organisation's reporting requirements.

Click on Search.

NOTE: This is a generic example of selections.

The search results. 

Select View transactions due to see the list and then generate the export file from there. 

Select Process transactions due to go directly to generate the export file. 

The process has been completed successfully. 

Click through on the batch to proceed.

Click through to view, and then complete the export. 

With the status as Captured, you can export a test file that can be uploaded to the SARS Test Platform.

You can also still add or remove donation transactions.

When you are satisfied with the data you are submitting to SARS, select Update and change the status to Completed. 

Once the status  has been changed, you will no longer be able to make changes to the batch.

Select Action > Export to generate the SARS export file.

Your files will look something like this.

 

They are ready to upload to SARS.

The SARS IT3(d) file has been generated and is ready to submit.
